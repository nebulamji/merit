# Code of conduct

Be useful, be honest, be kind. This project follows the spirit of the [Contributor Covenant 2.1](https://www.contributor-covenant.org/version/2/1/code_of_conduct/).

- Disagree with ideas, not people.
- No harassment, discrimination, or personal attacks.
- Assume good faith; ask before assuming otherwise.
- Do not publish other people's private information.

Maintainers may remove comments, issues or contributions that break these rules. To report a problem, use the repository's private **Security → Report a vulnerability** channel and say it is a conduct report.
